## GitHub README / project description

Open Spot helps appointment-based local businesses fill last-minute cancellations with SMS alerts to opted-in waitlist clients. Merchants manually validate every confirmed appointment.

Official website: https://open-spot.ca

Stack: Next.js, TypeScript, Supabase, Twilio (optional). Bilingual fr-CA / en-CA.
