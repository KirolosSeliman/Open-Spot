# Brand Profile Setup Checklist

Use this after creating or updating public profiles for Open Spot.

## Profiles

- [ ] LinkedIn Company Page created with consistent name **Open Spot**
- [ ] Google Business Profile created **only if appropriate** (real operating business; no fake address)
- [ ] GitHub README links to https://open-spot.ca
- [ ] X / Twitter profile created if useful
- [ ] Facebook page created if useful

## Search engines

- [ ] Google Search Console verified (prefer DNS TXT for `open-spot.ca`)
- [ ] Bing Webmaster Tools verified
- [ ] Sitemap submitted: https://open-spot.ca/sitemap.xml
- [ ] Key URLs from `docs/seo/indexing-urls.txt` inspected or submitted (without spamming)

## Brand consistency

- [ ] Logo uses official mark: `/brand/open-spot-logo-mark.png`
- [ ] Brand name **Open Spot** consistent; French alternate **2e Chance RDV** where relevant
- [ ] Website URL **https://open-spot.ca** on all profiles
- [ ] No old Vercel URL (`*.vercel.app`) on customer-facing profiles
- [ ] No fake physical address on Google Business Profile
- [ ] No fake reviews or star ratings
- [ ] No fake client logos or testimonials
- [ ] No duplicate inconsistent brand names (avoid unrelated "Open Spot" products)

## Product messaging

- [ ] Copy states **manual merchant validation** for final appointments
- [ ] Copy does **not** promise automatic booking confirmation
- [ ] Copy does **not** claim #1 ranking, thousands of clients, or press features without proof
